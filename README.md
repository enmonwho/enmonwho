## Featured Projects

**Emergency Department Discrete-Event Simulation**  
Python and SimPy simulation model for studying patient flow and healthcare resource allocation. The model evaluates how different staffing and capacity configurations influence waiting times, queues, length of stay, and resource utilization.

**Predictive Model for Financial Markets**  
Research-oriented predictive modeling project exploring patterns in financial-market data. Current development focuses on feature engineering, market regime analysis, model comparison, validation, and evaluating predictive performance across different conditions.

**Inflation Forecasting and Analysis**  
Data science project analyzing Philippine CPI and inflation trends using Random Forest, K-Means clustering, ARIMA, and SARIMA for pattern discovery, segmentation, and forecasting.

**CampusNav**  
Campus navigation and route optimization system for Mapúa Intramuros. The campus is represented as a weighted graph and routes are calculated using Dijkstra's Algorithm and A*, with support for wheelchair-accessible and rain-protected paths.

**Milk Bank Management System**  
Management platform for handling the human milk donation workflow, including donor applications, screening, scheduling, laboratory testing, pasteurization, inventory management, dispensing, and role-based access.

**Lakbye**  
Travel planning and management platform for organizing routes, day-by-day itineraries, budgets, bookings, packing lists, profiles, and travel journals within a unified workspace.

**FRUMS — Facial R Us Management System**  
Multi-branch skincare business management system covering appointments, services, clients, inventory, sales, branches, user roles, and audit logs.
